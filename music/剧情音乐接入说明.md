# 《斗破苍穹》动态剧情音乐接入说明

## 使用目标

音乐跟随剧情状态变化，但不要每一句对话都换曲。通常一条背景音乐至少保持 20 秒；只有人物登场、异火出现、突破、Boss 登场等明确事件才插入短过场。

## 剧情系统需要输出的四个字段

```json
{
  "scene": "wutan_city",
  "mood": "daily",
  "event": null,
  "intensity": 1
}
```

- `scene`：地点或玩法，例如乌坦城、魔兽山脉、炼药、云岚宗。
- `mood`：当前主要情绪，例如日常、神秘、温情、紧张、战斗。
- `event`：一次性关键事件，没有时使用 `null`。
- `intensity`：1～3，表示平静、发展、高潮。

## 推荐切换逻辑

1. 优先判断 `event`。命中关键事件时播放短过场。
2. 短过场结束后，根据 `scene + mood` 选择循环 BGM。
3. 普通场景变化使用 1.5 秒等功率交叉淡化。
4. 进入战斗时使用 0.6 秒切换；战斗结束先播放胜利短过场，再回到场景音乐。
5. 相同音乐已经播放时不重新开始，只调整音量。
6. 新状态持续不足 3 秒时不切换，避免剧情文本快速刷新造成音乐抖动。

## 典型剧情示例

| 剧情 | 音乐处理 |
|---|---|
| 萧家日常、坊市行动 | 播放《乌坦晨火》循环 |
| 戒指异动、神秘低语 | 交叉淡入《戒中残魂》 |
| 药老第一次完整现身 | 暂停背景层，播放《一缕残魂》，结束后回到《戒中残魂》 |
| 开始炼药 | 播放《炉心百炼》；火候升高时可叠加节奏层 |
| 魔兽山脉探索 | 播放《魔兽山脉》 |
| 敌意出现但尚未开战 | 切换《危机暗涌》 |
| 正式进入战斗 | 对齐节拍切换《逆焰而战》 |
| Boss 登场 | 播放《强敌压境》，随后进入战斗循环 |
| 发现或吞噬异火 | 播放《异火现世》 |
| 突破境界 | 播放《破境》后回到当前场景音乐 |
| 云岚宗相关剧情 | 播放《云岚之上》 |
| 塔戈尔沙漠与蛇人族区域 | 播放《塔戈尔风沙》 |
| 师徒、家人、伙伴的安静剧情 | 播放《故人灯火》 |

## 音量建议

- 普通背景音乐：游戏总线的 55%～65%。
- 战斗音乐：65%～75%。
- 短过场：75%，播放时将背景音乐降到 20%，不要直接硬停。
- 角色对白或语音出现时：背景音乐再自动降低约 6 dB。

具体文件名、触发标签、优先级和淡化时间见 `dynamic_bgm/music_manifest.json`。
