# 《斗破苍穹》游戏原创音乐设计

## 核心判断

《斗破苍穹》的音乐不应只做成常见的“仙侠古风”。它的独特气质来自四件事：

1. **逆境成长**：萧炎从跌落谷底到重回巅峰，旋律必须有向上攀升的力量。
2. **异火与炼药**：火焰既危险又神圣，需要不稳定的半音火纹、呼吸感和能量脉冲。
3. **西北荒域**：乌坦城、加玛帝国与沙漠不是江南水墨，声音应更干燥、粗粝、辽阔。
4. **师徒传承**：药老带来的不是单纯神秘感，而是古老、克制、可靠的精神支点。

因此，整体采用 **东方五声音阶 + 电影交响 + 荒域打击乐 + 火焰音色设计**。保持东方玄幻辨识度，同时具备游戏战斗所需的力度。

## 已制作 Demo

- `斗破苍穹_焚天少年_主主题Demo.mp3`：约 95 秒的完整试听版。
- `斗破苍穹_焚天少年_主主题Demo.wav`：无损母带，44.1 kHz / 16 bit / 立体声。
- `斗破苍穹_荒域行歌_探索循环.ogg`：约 43 秒，可用于地图或主城探索的循环草案。
- `斗破苍穹_焚天少年_主题旋律.mid`：主题、和声、低音与打击乐的 MIDI 草案，方便在宿主软件中重新配器。

所有旋律均为本次原创，没有复刻动画、影视或其他游戏的既有配乐。

## 动态剧情 BGM 包

`dynamic_bgm/` 是供剧情系统实际调用的第一版素材包，包含：

- 9 条场景与情绪循环音乐；
- 6 条关键剧情短过场；
- 一段按场景串联的 MP3 试听；
- `music_manifest.json` 剧情触发配置；
- `剧情音乐接入说明.md` 穿插与切换规则。

这套音乐不是按固定歌单顺序播放。游戏应根据剧情输出的 `scene`（场景）、`mood`（情绪）、`event`（事件）和 `intensity`（强度）选择音乐，并在小节边界淡入淡出。

## 主主题：《焚天少年》

- **使用场景**：标题界面、角色序章、重大版本宣传、萧炎突破后的剧情回收。
- **调式**：D 小调五声音阶为主，异火段短暂加入降二级与升七级，制造危险感。
- **拍号**：6/8 拍。
- **速度**：附点四分音符每分钟 84 拍。
- **情绪曲线**：余烬低语 → 少年立志 → 荒域启程 → 异火觉醒 → 师徒余韵。
- **主要音色**：箫/埙感吹管、琵琶感拨弦、二胡感领奏、低弦、圆号感合成铜管、战鼓、火星纹理。

### 三个核心音乐动机

| 动机 | 音程轮廓 | 对应含义 | 使用方式 |
|---|---|---|---|
| 萧炎动机 | 主音 → 小三度 → 四度 → 五度 | 从低谷持续向上 | 主界面、升级、逆转战局 |
| 药老动机 | 高音 → 五度 → 四度 → 主音 | 古老传承落回现实 | 指引、炼药、师徒剧情 |
| 异火动机 | 半音摩擦 → 突然上冲 → 留白 | 危险、吞噬、蜕变 | Boss 阶段切换、异火出现、突破 |

## 游戏内自适应规则

- **探索音乐**保留底层环境、拨弦和低弦三个可独立开关的音层。
- **遇敌时**不立即换曲，先加入心跳低鼓与异火脉冲；进入战斗后再对齐小节切换。
- **Boss 血量 50% 以下**加入异火动机与高频火星层，避免只靠提高音量制造紧张。
- **释放佛怒火莲**前抽走低频约半拍，技能命中时再让战鼓、铜管和低弦同时回归。
- **炼药玩法**用节奏密度反馈火候，不用持续提示音打断音乐；失败时让节奏失衡并自然熄灭。
- 所有探索曲建议以 **8 或 16 小节**为循环单位，并保留 1.5–2 秒自然混响尾音供音频引擎交叉淡化。

## 后续正式制作建议

当前 Demo 是用于确认旋律、结构与世界观方向的合成草案。正式版建议将吹管、二胡、琵琶和战鼓替换为真人或高质量音源，并分出 `环境 / 节奏 / 旋律 / 战斗增强` 四组音轨，方便游戏运行时自适应混音。
