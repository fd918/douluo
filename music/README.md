# 《斗罗大陆人生模拟器》原创动态音乐

正式游戏音乐已经输出到 `game/public/audio/douluo/`，由 `game/src/audio/` 中的控制器按剧情状态播放。所有旋律均为本项目原创合成，不复刻动画、影视或其他游戏配乐。

## 当前曲目

- 循环 BGM：诺丁初晴、蓝银微光、怪物晨练、星斗林语、暗线逼近、魂环共振、伙伴灯火、远海星潮。
- 事件短音效：武魂觉醒、魂环入体、魂力突破、强敌现身、战斗胜利、危险逼近。

整体采用东方五声音阶、电影弦乐、木质拨弦、箫笛感领奏和克制的战鼓。诺丁城强调清朗生活感，史莱克强调团队节奏，星斗森林强调呼吸与空间，魂师战斗强调魂环共振和推进力。

## 重新生成

生成脚本为 `generate_douluo_bgm.py`，底层合成工具为 `synth_utils.py`。脚本会直接更新正式音频目录和 `music_manifest.json`；重新生成后应在 `game` 目录运行 `npm run test:audio`。
