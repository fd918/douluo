# 版本记录

## 1.1.0 - 2026-08-16

- 真实手机改为全屏游戏模式，不再显示设备选择器、手机外框、模拟状态栏和键盘；电脑预览保留原设备外观
- 主线从五章扩展为十章、35 个可达节点和八个结局，新增天斗暗潮、第二魂环、精英赛、瀚海航路与海神岛
- 新增三种第二魂环、第二魂技战斗按钮、三种高阶魂兽、五件剧情/成长物品与十一项成就
- GitHub Pages 提供 `https://fd918.github.io/douluo/` 短地址，Sites Worker 继续以服务端环境变量保护 AI 密钥
- 添加受限 CORS、GitHub Pages 子路径资源适配、剧情可达性和手机全屏自动化验收

## 1.0.0 - 2026-08-16

- 建立 `codex/douluo-recovery` 正式恢复线，斗破剧情、美术和音乐保留在归档分支但不进入游戏
- 保留五章剧情树、四结局、战斗、关系、行囊、时间线存档和既有 `v2` 浏览器存档兼容
- 新增斗罗世界设定圣经，统一正式版本的角色、地点、力量体系和禁用词边界
- 生成 8 条原创斗罗循环 BGM 与 6 条事件短音效，接入场景切换、交叉淡化、后台暂停和音乐设置
- AI 支持主服务失败后自动尝试备用服务，并增加每分钟和每日请求保护
- 完成音频、服务端、运行时、生产构建与手机页面验收，为 GitHub 和 Sites 公网发布做好准备

## 0.6.2 - 2026-08-15

- 完成本机 ChatGPT/Codex 订阅桥的兼容性验证，游戏现有 OpenAI 适配层无需修改即可调用
- 验证自由行动、人物对话和滚动摘要三类结构化输出，推荐本机开发使用 `codex-fast`（GPT-5.6-Luna）
- 验证 5 个角色请求同时执行，全部成功且总耗时约 17 秒；保留 120 秒超时和本地剧情兜底以覆盖上游慢响应
- 补充本机桥配置位置、启动顺序、安全边界及不可用于公网 Worker 的限制

## 0.6.1 - 2026-08-15

- 新增每 12 个游戏轮次触发一次的滚动剧情摘要，合并旧摘要与本阶段时间线事件
- 摘要直接写入当前时间线快照，不增加游戏轮次；AI 不可用时使用本地压缩结果
- 每名角色的完整对话窗口调整为最近 10 轮，即 20 条玩家与角色消息
- 人物对话和自由行动会携带阶段剧情摘要，不再重复发送全部长期经历
- 普通请求统一优先关闭深度思考；自由行动、人物对话和摘要的输出上限分别降至 480、360、520 Token
- 服务端测试覆盖对话窗口裁剪、阶段摘要、关闭深度思考和分类型 Token 上限

## 0.6.0 - 2026-08-15

- 新增同源 `/api/ai/generate` 服务端适配器，供应商密钥不进入浏览器代码
- 自由行动优先由 AI 结合当前章节、线索、玩家状态和共同记忆续写剧情
- 小舞、戴沐白、奥斯卡、宁荣荣的自由对话优先使用 AI，并生成可持久化的共同记忆和好感变化
- AI 请求加入输入长度、输出 Token、超时、残缺 JSON 修复、字段校验、缺失字段补全与供应商兼容性重试限制
- AI 未配置、超时、返回异常或供应商不可用时自动回退现有本地规则，不中断剧情和存档
- 本地 Vite 开发服务与部署 Worker 共用同一套 OpenAI 兼容适配逻辑
- 完成 Agnes `agnes-2.5-flash` 自由行动、人物对话和部署 Worker 自动化测试

## 0.5.0 - 2026-08-15

- 新增 NPC 结构化长期记忆；剧情选择、自由行动、人物对话和主动事件都会生成记忆摘要
- 人物档案新增“共同记忆”，区分行动、对话、拜访、冲突、心意和任务来源
- 对话窗口继续保留最近消息，长期记忆独立保存关键摘要，刷新页面后仍可恢复
- 新增小舞主动拜访、戴沐白主动冲突、宁荣荣主动心意和奥斯卡主动任务四类事件
- 主动事件根据人物好感、累计经历、当前轮次和已完成记录决定是否触发，已发生事件不会重复触发
- 主动事件出现时暂时锁定普通剧情选择，玩家回应后同步更新好感、叙事、笔记、记忆和时间线节点
- 旧版 `v1` / `v2` 存档缺少记忆字段时会自动补齐默认值，不覆盖原有剧情、战斗与行囊进度
- 完成主动拜访、事件回应、对话记忆、刷新持久化和人物档案记忆展示的浏览器验收

## 0.4.0 - 2026-08-15

- 新增独立的本地剧情引擎与五章长期剧情树，告别诺丁城开场选项重复循环
- 三条开场路线会继续分化至星斗森林、商队峡谷、史莱克试炼、地下实验室、大斗魂场或秘密交易
- 选择会持续改变魂力经验、金魂币、伙伴好感以及证据、信任、守护和力量等隐藏条件
- 后期选项会根据此前条件显示可用或锁定状态，并给出明确的解锁要求
- 新增大陆守望者、怪物同盟、魂核君临者和自由行者四个结局及收集进度
- 结局后可保留已发现记录开启新时间线，也可在档案页回溯任意历史节点形成新分支
- 剧情叙事与旅行、战斗等开放世界叙事分离，非剧情操作不再覆盖主线内容
- 兼容既有 `v1` / `v2` 本地存档，缺少结构化剧情字段的旧档会安全回到诺丁城剧情起点
- 完成大陆守望者整线贯通、重复游玩继承、档案节点以及 iPhone / Pixel 10 布局验收
