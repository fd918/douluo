# 版本记录

## 0.5.0 - 2026-08-15

- 新增 NPC 结构化长期记忆；剧情选择、自由行动、人物对话和主动事件都会生成记忆摘要
- 人物档案新增“共同记忆”，区分行动、对话、拜访、冲突、心意和任务来源
- 对话窗口继续保留最近消息，长期记忆独立保存关键摘要，刷新页面后仍可恢复
- 新增小舞主动拜访、戴沐白主动冲突、宁荣荣主动心意和奥斯卡主动任务四类事件
- 主动事件根据人物好感、累计经历、当前轮次和已完成记录决定是否触发，已发生事件不会重复触发
- 主动事件出现时暂时锁定普通剧情选择，玩家回应后同步更新好感、叙事、笔记、记忆和时间线节点
- 旧版 `v1` / `v2` 存档缺少记忆字段时会自动补齐默认值，不覆盖原有剧情、战斗与行囊进度
- 完成主动拜访、事件回应、对话记忆、刷新持久化和人物档案记忆展示的浏览器验收

## 0.4.0 - 2026-08-15

- 新增独立的本地剧情引擎与五章长期剧情树，告别诺丁城开场选项重复循环
- 三条开场路线会继续分化至星斗森林、商队峡谷、史莱克试炼、地下实验室、大斗魂场或秘密交易
- 选择会持续改变魂力经验、金魂币、伙伴好感以及证据、信任、守护和力量等隐藏条件
- 后期选项会根据此前条件显示可用或锁定状态，并给出明确的解锁要求
- 新增大陆守望者、怪物同盟、魂核君临者和自由行者四个结局及收集进度
- 结局后可保留已发现记录开启新时间线，也可在档案页回溯任意历史节点形成新分支
- 剧情叙事与旅行、战斗等开放世界叙事分离，非剧情操作不再覆盖主线内容
- 兼容既有 `v1` / `v2` 本地存档，缺少结构化剧情字段的旧档会安全回到诺丁城剧情起点
- 完成大陆守望者整线贯通、重复游玩继承、档案节点以及 iPhone / Pixel 10 布局验收

## 0.3.0 - 2026-08-15

- 新增魂力经验、等级突破、生命、攻击、防御、速度和控制属性
- 新增第一魂环“百年蓝银藤环”和第一魂技“蓝银缠绕”，魂技可在战斗中限制敌人反击
- 新增植物克水、水克火、火克植物的属性克制倍率，以及兽属性中性规则
- 新增三类百年魂兽、回合战斗、胜负状态、经验、金魂币和战利品结算
- 行囊物品支持使用、购买、出售、装备和卸下，装备会实时改变角色属性
- 本地存档升级为 `v2` 时间节点树；剧情、旅行、人物互动、修炼、战斗和经济操作都会生成节点
- 时空回溯支持选择任意历史节点，并从落点建立新支线，不删除原有时间线
- 旧版 `v1` 本地存档会自动迁移为时间线根节点
- 完成 iPhone、Pixel 10、375px 小屏及核心交互验收

## 0.2.0 - 2026-08-15

- 世界地图地点支持点击查看所属区域、路程、耗时、风险和区域线索
- 诺丁城、史莱克学院、星斗大森林支持实际旅行，并同步到达剧情、主线节点与时间线存档
- 海神岛显示明确的未解锁状态和解锁提示
- 小舞、戴沐白、奥斯卡、宁荣荣新增独立人物档案和专属剧情
- 新增推荐话题、自由输入、本地角色回应、对话记录和四人独立好感度
- 剧情选择与对话会形成共同记忆，并可触发角色主动拜访、冲突、心意和任务
- 旧存档会自动补齐人物关系与对话数据，不覆盖既有进度
- 完成 iPhone 与 Pixel 10 交互验收
