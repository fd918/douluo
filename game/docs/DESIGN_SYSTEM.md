# 视觉与交互规范

## 已确认方向

- 风格：第三套“暗夜魂力史诗”方案
- 基调：深海军蓝、黑蓝面板、古金描边、蓝紫魂力辉光
- 视觉关键词：克制、神秘、沉浸、东方玄幻、轻量游戏 HUD
- 字体：中文标题使用宋体气质，正文使用清晰易读的无衬线字体

## 页面结构

- 手机底部固定五栏导航：剧情、世界、关系、行囊、档案
- 真实手机（小于 768px 或触摸主设备）直接全屏运行游戏，使用 `100dvh` 与系统安全区；不显示设备外框、模拟状态栏或模拟键盘
- 电脑浏览默认保留 iPhone / Pixel 10 原型预览；`?preview=1` 强制预览，`?native=1` 强制全屏，仅用于调试
- 核心数值使用金色，武魂与路径线索使用青蓝色，好感变化使用绿色
- 可点击区域最小按手机触控尺寸设计，正文内容可纵向滚动
- NPC 主动行动使用剧情页内嵌事件卡片，显示人物头像、行动类型、触发依据和两个明确回应
- NPC 长期记忆统一放在人物档案的“共同记忆”区域，关键记忆使用金色左边线，普通记忆使用中性边线
- 地图地点使用地图浮层按钮，当前位置使用青色描边，未解锁地点同时显示锁定图标和弱化颜色
- 地点详情、人物档案和人物对话统一使用手机范围内的底部弹层，不跳出设备画布
- 人物弹层采用“档案—好感—专属剧情—对话”的固定信息顺序
- 地图、角色卡、推荐话题和主要操作按钮的触控高度不小于 44px
- 战斗、物品详情与商店结算统一使用手机范围内的底部弹层，关闭后返回原页面位置
- 战斗生命使用绿色进度条，敌方生命使用红色进度条；克制关系必须同时显示文字和倍率，不能只依赖颜色
- 行囊、商店与拍卖使用同一套物品语义，通过“我的行囊 / 诺丁商店 / 魂师拍卖”三段按钮切换
- 时间线使用节点、连线、分支名称和当前节点文字共同表达状态；回溯按钮触控高度不小于 44px
- 长时间线节点启用按需渲染优化，底部导航始终固定且正文预留安全区
- 剧情页固定显示章节、时间线轮次、当前任务和场景标题；条件不足的选项使用锁定图标并直接说明解锁要求
- 结局页使用独立金色卡片展示第一卷/最终结局与八结局收集进度，已发现和未发现状态不能只依赖颜色区分
- 武魂选择使用两列卡片，必须同时显示名称、品质、定位和初始魂技；360px 以下自动改为单列
- 世界导演、势力声望、可结识角色与随机支线沿用暗蓝面板、金色行动和青色状态，不另建一套视觉体系
- 战斗持续状态使用文字药丸标签，同时标明作用对象和剩余回合，不能只依赖颜色

## 角色资产

- 小舞：黑色长发、蝎尾辫、粉色气质、灵动
- 戴沐白：金色长发、深蓝双瞳、冷峻
- 奥斯卡：桃花眼、少年感、自然棕色系
- 宁荣荣：齐耳短发、白皙、贵族配饰
- 头像统一使用圆形裁切、魂力色描边和暗色背景

## 资产位置

所有游戏视觉资产统一保存在 `public/game-assets/`，界面不得再使用空头像或临时占位图。

## 音乐与声音

- 正式音乐统一保存在 `public/audio/douluo/`，不得引用归档的斗破曲目。
- 音乐根据场景、情绪、事件和强度自动选择，并使用交叉淡化避免突兀切断。
- 音乐设置入口位于“档案”页，触控高度不小于 44px，同时显示图标、文字状态和明确操作。
- 剧情页右上角固定提供 44×44px 声音快捷开关，与档案页共用状态；图标按钮必须提供明确的无障碍名称。
- 剧情选择使用轻量确认音，锁定选项不播放，确认音与背景音乐共用静音设置。
- 浏览器首次真实交互后才能解锁声音；页面进入后台时暂停，回到前台后恢复。
- 行囊物品使用 `public/game-assets/items/` 中的一物一图游戏原画：信件、钱袋、药草、笔记、香炉、护腕、布甲、精华、魂晶、徽章、航图、潮汐甲、药剂和两类魂骨必须按外形可直接辨认；详情弹层使用暗蓝底、古金描边和青紫能量点缀。
- 手机运行时优先加载 `*-mobile.webp` 衍生图，原始 PNG 只作为源资产保留；首屏图片明确尺寸，非首屏人物头像按需加载。
- 首次开局使用暗蓝半透明序章卡承载世界介绍，保留“随时继续”出口，不强制用户等待朗读完成。
- 旁白控件统一为开关、暂停/继续、重播三个 44×44px 圆形按钮；显示“正在自动朗读”等文字状态，不只依赖图标传达。
- 删除角色、清空存档等不可撤销操作必须使用手机范围内的二次确认弹层，先说明影响范围，再把“确认清除”和“取消保留”分为独立的 48px 触控按钮。
