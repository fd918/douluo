# 视觉与交互规范

## 已确认方向

- 风格：第三套“暗夜魂力史诗”方案
- 基调：深海军蓝、黑蓝面板、古金描边、蓝紫魂力辉光
- 视觉关键词：克制、神秘、沉浸、东方玄幻、轻量游戏 HUD
- 字体：中文标题使用宋体气质，正文使用清晰易读的无衬线字体

## 页面结构

- 手机底部固定五栏导航：剧情、世界、关系、行囊、档案
- 核心数值使用金色，武魂与路径线索使用青蓝色，好感变化使用绿色
- 可点击区域最小按手机触控尺寸设计，正文内容可纵向滚动
- NPC 主动行动使用剧情页内嵌事件卡片，显示人物头像、行动类型、触发依据和两个明确回应
- NPC 长期记忆统一放在人物档案的“共同记忆”区域，关键记忆使用金色左边线，普通记忆使用中性边线
- 地图地点使用地图浮层按钮，当前位置使用青色描边，未解锁地点同时显示锁定图标和弱化颜色
- 地点详情、人物档案和人物对话统一使用手机范围内的底部弹层，不跳出设备画布
- 人物弹层采用“档案—好感—专属剧情—对话”的固定信息顺序
- 地图、角色卡、推荐话题和主要操作按钮的触控高度不小于 44px
- 战斗、物品详情与商店结算统一使用手机范围内的底部弹层，关闭后返回原页面位置
- 战斗生命使用绿色进度条，敌方生命使用红色进度条；克制关系必须同时显示文字和倍率，不能只依赖颜色
- 行囊与商店使用同一套物品卡片，通过“我的行囊 / 诺丁商店”分段按钮切换
- 时间线使用节点、连线、分支名称和当前节点文字共同表达状态；回溯按钮触控高度不小于 44px
- 长时间线节点启用按需渲染优化，底部导航始终固定且正文预留安全区
- 剧情页固定显示章节、时间线轮次、当前任务和场景标题；条件不足的选项使用锁定图标并直接说明解锁要求
- 结局页使用独立金色卡片展示本轮结局与四结局收集进度，已发现和未发现状态不能只依赖颜色区分

## 角色资产

- 小舞：黑色长发、蝎尾辫、粉色气质、灵动
- 戴沐白：金色长发、深蓝双瞳、冷峻
- 奥斯卡：桃花眼、少年感、自然棕色系
- 宁荣荣：齐耳短发、白皙、贵族配饰
- 头像统一使用圆形裁切、魂力色描边和暗色背景

## 资产位置

所有游戏视觉资产统一保存在 `public/game-assets/`，界面不得再使用空头像或临时占位图。

## 音乐与声音

- 正式音乐统一保存在 `public/audio/douluo/`，不得引用归档的斗破曲目。
- 音乐根据场景、情绪、事件和强度自动选择，并使用交叉淡化避免突兀切断。
- 音乐设置入口位于“档案”页，触控高度不小于 44px，同时显示图标、文字状态和明确操作。
- 浏览器首次真实交互后才能解锁声音；页面进入后台时暂停，回到前台后恢复。
