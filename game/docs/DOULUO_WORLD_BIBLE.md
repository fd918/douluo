# 斗罗世界设定圣经

## 产品边界

- 产品名称：斗罗大陆人生模拟器。
- 玩家是生活在斗罗大陆的原创角色，可以影响支线、关系与局部事件，但不会被强制替代为原著主角。
- 正式主线覆盖诺丁城、史莱克学院、星斗/落日森林、索托城、天斗精英赛、瀚海航路和海神岛。
- 固定剧情保证任务与结局可完成，AI负责自由行动、人物对话和局部叙事变化。

## 力量体系

- 核心概念只使用武魂、魂力、魂师、魂环、魂技、魂兽和魂骨等斗罗体系。
- 初始武魂可选蓝银草、碧藤刃、澄潮珠、赤羽隼、玄甲犀或星辉罗盘，每种拥有独立属性偏向与初始魂技；蓝银草继续兼容“蓝银缠绕”和三种第二魂环旧路线。
- 成长以魂力经验、魂力等级、生命、攻击、防御、速度和控制为主。
- 不得出现斗气、斗者、斗师、异火、炼药师等斗破体系名词。

## 角色与地点

- 核心人物：小舞、戴沐白、奥斯卡、宁荣荣；扩展人物包括朱竹清、马红俊、玉小刚、弗兰德、独孤雁、叶泠泠、水冰儿、火舞及两位原创角色。
- 内容目录覆盖十二地点、十四类魂兽与七大势力，具体解锁由 `src/content/douluoWorldContent.ts` 统一维护。
- 人物回应必须保持档案中的性格、好感、共同记忆和当前剧情状态连贯。
- 不照抄小说原文，不复刻动画、影视或其他游戏的对白、画面和音乐。

## 首发剧情原则

- 第一章从诺丁城雨后发光脚印开始，逐步揭开非法魂力实验支线。
- 玩家可偏向证据、伙伴、守护或力量，最终形成大陆守望者、怪物同盟、魂核君临者或自由行者结局。
- AI可以改变事件表达、线索细节和关系记忆，但不能凭空赠送无敌能力，也不能跳过本地剧情树的关键条件。
- AI 世界导演只能从给定势力、地点、物品和标记白名单中选择，并受声望、金币和经验硬上限约束；模型不可用时必须使用同一事件的本地结果。
- 每次新增剧情、角色、美术或音乐前，先检查本文件与 `docs/DESIGN_SYSTEM.md`。

## 音乐语义

- 诺丁城：清朗、生活感、初次冒险。
- 蓝银谜团：植物魂力、旧井、脚印和隐秘实验。
- 史莱克：训练、伙伴、竞争与团队节奏。
- 星斗森林：空间、呼吸、魂兽与未知危险。
- 魂师战斗：魂环共振、技能节奏与克制关系。
- 禁止使用萧炎、药老、异火、乌坦城、云岚宗等斗破人物、地点或音乐动机。
