# 版本记录

## 0.2.0 - 2026-08-16

- 中台由本机网关升级为公网 AI 控制台，本机页面通过受保护接口直接管理 Sites Worker
- 每个服务商支持多个模型、默认模型选择、模型列表同步和手动添加
- 支持设置每百万输入/输出 Token 的人民币价格并自动估算费用
- 运营概览新增输入 Token、输出 Token 和当日预估费用，调用明细显示单次费用
- 服务商、模型、价格、策略和调用记录持久化到公网 D1，本机关机后公网继续运行
- 整体字号、表格和表单尺寸放大，提升长时间阅读和操作体验

## 0.1.0 - 2026-08-16

- 新增独立深色 AI 运营看板，适配桌面、手机和横屏
- 新增服务商可视化配置、启停、主服务切换与连通测试
- 新增 OpenAI 兼容统一网关与主备容灾
- 新增 SQLite 持久化额度、调用记录与运行设置
- 新增本地密钥 AES-256-GCM 加密和可视化掩码
- 新增 Token、延迟、成功率、降级救活、错误可视化和筛选
- 导入 Agnes 并验证真实调用，预置云瞻反代的地址与模型
- 新增斗罗游戏一键接入和恢复原配置脚本
