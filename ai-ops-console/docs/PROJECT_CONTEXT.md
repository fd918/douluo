# 项目背景

## 目标

为《斗罗大陆人生模拟器》提供一个本机可视化、公网持久运行的 AI 运营中台，让非技术用户无需修改游戏代码或重新部署即可管理公网服务商、模型、价格、主备容灾、限流和调用记录。

## 当前阶段

0.2.0 公网控制版已完成。中台页面运行于 `127.0.0.1:4180`，通过本地管理凭证控制公网 Sites Worker；Mac 关闭后公网继续使用 D1 中最后保存的配置。

## 已完成

- 服务商可视化新增、编辑、启停、主服务切换和连通测试
- OpenAI 兼容 `/v1/chat/completions` 统一网关
- 主服务失败后按优先级自动降级
- D1 持久化服务商、模型价格、额度、设置和调用记录
- 每来源每分钟/每日限流，重启后计数不丢失
- 输入/输出 Token、预估费用、延迟、成功率、错误和降级救活可视化
- 服务商多模型选择、模型列表同步、手动模型和人民币价格设置
- 密钥 AES-GCM 云端加密，浏览器只显示掩码
- 玩家剧情与对话原文不进运营日志
- 现有 Agnes 服务已导入并通过真实请求验证
- 云瞻反代的地址和模型已预置，待在中台内完成密钥确认后启用

## 下一阶段

如需在多台电脑管理，可把可视化页面迁移到带登录保护的独立服务器；公网游戏本身不依赖这一步。
