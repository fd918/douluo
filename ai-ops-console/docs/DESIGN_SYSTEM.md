# 视觉与交互规范

- 定位：稳定、克制、易读的公网 AI 运营工具
- 主题：深蓝黑背景、青蓝主操作、绿色成功、红色异常、紫色备用路由
- 字体：中文使用系统无衬线字体，数据使用等宽数字
- 字号：正文与表格以 13–16px 为主，指标 30–40px，不使用低于 12px 的关键文字
- 导航：桌面左侧固定导航；620px 以下使用四栏底部导航
- 状态：不仅依赖颜色，同时显示文字、图标和数值
- 可访问性：图标统一使用 Lucide，图标按钮都有可读标签，焦点环可见，异步操作禁止重复点击
- 动效：150–300ms 轻量过渡，并支持 `prefers-reduced-motion`
- 数据图：柱状图同时显示图例、标题和可读文本；额度环必须同时显示百分比与已用/剩余次数
- 表单：模型价格统一使用“人民币 / 100 万 Token”，输入与输出价格分栏显示
