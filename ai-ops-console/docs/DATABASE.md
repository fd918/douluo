# 数据库说明

## 新增数据

- `ai_providers`：服务商名称、地址、加密密钥、优先级和最近健康状态
- `ai_provider_models`：服务商模型、默认选择、启用状态与输入/输出价格
- `ai_ops_settings`：每分钟/每日额度、自动降级和日志保留天数
- `ai_usage_events`：请求类型、服务商、成功/失败、输入/输出 Token、预估费用、延迟和错误摘要
- `ai_request_budgets`：经 SHA-256 处理的来源摘要与每分钟/每日计数

## 历史数据影响

正式数据位于游戏 Sites 项目的 D1，与 `ai_request_budgets` 共用数据库但使用独立表，不读写玩家存档，不删除历史限流数据。本机 SQLite 仅用于离线兼容。

## 备份与迁移

新增迁移为 `game/drizzle/0002_ai_ops_cloud.sql`，只创建新表和索引，可重复执行。服务商密钥由生产 Secret `AI_CONFIG_MASTER_KEY` 加密；修改或丢失该值后，旧密文无法解密，需要重新录入服务商密钥。

## 回滚

回滚公网版本时重新发布此前的 Sites 版本。新表保留不会影响旧 Worker，也不应主动删除，以便保留运营记录和再次升级。

## 验证

- 关闭本机中台后，公网游戏仍可调用最后保存的服务商
- 重启中台后服务商、模型价格、设置和额度计数仍然存在
- 将每日额度临时设为已用值以下时，网关返回 `429 / AI_DAILY_LIMIT`
- 数据库不存在剧情、人物对话或原始 IP 字段
