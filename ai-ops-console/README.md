# 斗罗 AI 运营中台

这是《斗罗大陆人生模拟器》的本机可视化 AI 运营中台。页面在 Mac 上运行，但服务商、模型、价格、主备切换、调用额度和日志都保存到公网控制层；关闭 Mac 后，公网游戏继续使用最后保存的配置。

## 已实现

- 可视化添加、编辑、启停和切换 OpenAI 兼容服务商
- 每个服务商可同步或手动添加多个模型，并选择默认模型
- 分别设置每百万输入/输出 Token 的人民币价格，自动估算费用
- 主服务失败后按优先级自动降级到备用服务
- 每分钟、每日 D1 持久化限流，刷新页面和本机关机都不会清空
- 调用量、成功率、输入/输出 Token、预估费用、平均延迟、降级救活和最近错误可视化
- 调用日志按服务商、类型和成功/异常筛选
- 服务商密钥由公网 Worker 使用 AES-GCM 加密，页面只显示掩码
- 日志只保存运营元数据，不保存玩家剧情、人物对话或原始 IP

## 本机运行

在 macOS 终端进入本目录：

```bash
cd "/Users/tanwenjie/Documents/ChatGPT/斗破/ai-ops-console"
npm run dev
```

中台地址：`http://127.0.0.1:4180/`。默认只监听本机，同一 Wi-Fi 中的其他设备不能打开。公网连接配置位于本目录 `.env.local`；该文件已经忽略 Git。

## 公网控制方式

页面通过 `.env.local` 中的 `OPS_CLOUD_URL` 和 `OPS_CLOUD_ADMIN_TOKEN` 管理公网 Worker。管理请求由本机页面直接发送到公网控制接口，避免本机服务器请求被站点防护误拦截。以后切换服务商、默认模型、价格或限流策略时，只需在页面保存；公网游戏立即生效，不需要重启本机服务或重新部署。

本机关闭后，管理页面暂时无法打开，但公网 Worker 与 D1 独立运行，不影响玩家。

## 让本地开发游戏通过中台调用

先启动中台，再执行：

```bash
npm run connect:game
```

项目会自动备份游戏原 AI 配置并切换到 `http://127.0.0.1:4180/v1`。修改后需重启游戏开发服务。

如需恢复游戏原配置：

```bash
npm run disconnect:game
```

## 本地数据与凭证

- 本地兼容数据库：`.data/ai-ops.sqlite`
- 本地兼容主密钥：`.data/master.key`
- 公网管理配置：`.env.local`
- 游戏 AI 配置备份：`../game/.env.aiops-backup.local`

上述内容均已忽略 Git。当前公网服务商配置以 D1 为准；迁移管理电脑时必须安全迁移 `.env.local`，不能把管理凭证写进公开文档或截图。
