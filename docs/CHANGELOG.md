# 版本记录

## 1.5.0 - 2026-08-16

- 将原著同行从 61 个重大场景扩展为 184 个连续场景；每个重大事件之间新增“余波”和“幕间准备”，补足学院日常、伤势、物资、训练复盘、关系交流与情绪后果
- 三档叙事节奏开始真正影响路线长度：沉浸约 184 段、标准约 123 段、快速约 62 段，核心事件与结局保持一致
- 新增 122 个细分生活场景及配套三选项、三人对白和原著时间锚点，完整默认路线与三个结局保持可达
- 人物关系、主动事件、地图和自由探索改为按稳定场景 ID 解锁，不再依赖容易随内容扩容失效的固定数字
- 原著同行新增 187 段固定 MP3 旁白，连同旧线共 283 段；云希负责日常与关系，云健负责觉醒、魂环、身份暴露、远海与终局
- 新建角色、世界序章和每次静态主线推进优先播放固定旁白；固定音频失败时自动回退设备中文系统语音，自由输入仍使用系统语音
- 更新场景密度、完整路线、对白覆盖、固定旁白映射和音频资源完整性测试

## 1.4.0 - 2026-08-16

- 新增 61 个连续原著同行场景，从六岁武魂觉醒、诺丁六年、第一次猎魂一路覆盖史莱克、魂师精英赛、五年之约、海神岛、嘉陵关与原著之后的人生选择
- 新角色不再开局自带魂环；第一、第二魂环会在对应猎魂场景中按六种武魂动态生成，获得第一魂环后才开放自由战斗
- 角色创建新增出生地、家庭背景、人生目标、个人秘密和三档叙事节奏，相关设定同时进入本地模板替换与 AI 上下文
- 剧情页新增原著时间锚点、61 段主线进度、18 组关键人物对话和最近五次选择回顾
- 小舞、戴沐白、宁荣荣、奥斯卡的关系与主动事件按原著相识时序解锁；世界地点、随机探索和战斗也随年代开放
- 更新序章与世界任务文案，清除新游戏中的“发光脚印/魂晶阴谋”旧开场；旧存档仍安全保留原支线
- AI 续写新增原著时间锚点、玩家出身与人生目标约束，禁止提前登场、替代原著人物关键决定或泄露未来事件
- 新增原著同行场景密度、模板替换、完整路线、魂环里程碑与全部结局可达性测试

## 1.3.3 - 2026-08-16

- “档案”页新增玩家自带 AI 设置，可编辑 OpenAI 兼容 API 地址、模型 ID 和玩家自己的密钥
- 默认预填 Agnes API 地址与 `agnes-2.5-flash`，不在代码、构建产物或 GitHub 中内置真实密钥
- 配置只保存在当前浏览器；保存后立即测试，成功才启用 AI，401、超时、跨域或无效响应都会保持本地剧情模式
- GitHub Pages 构建改为玩家直连模式，未配置时不再请求受跨域限制的 Sites 接口；Sites 版本仍保留服务端代理、D1 限流和运营中台
- 直连模式沿用剧情长度、关闭深度思考、结构校验、世界白名单和数值上限，并增加独立自动化测试

## 1.3.2 - 2026-08-16

- 96 段固定旁白升级为双男声有声小说方案：云希负责大多数剧情，云健负责序章、武魂觉醒、重大转折和结局
- 世界序章和剧情转场改写为更自然的有声小说句式，增加短句、段落、留白与戏剧停顿，减少逐字播报感
- 全部旁白改为 44.1kHz 单声道 64kbps 纯人声，增加轻动态压缩、极轻空间感和统一响度，不在 MP3 内嵌 BGM
- 游戏场景 BGM 在旁白期间柔和压低 9dB，旁白结束后恢复；音乐保持连续，不因每段旁白重新开始或中断
- 音乐首次解锁改用内嵌 20 毫秒静音片段，不再为解锁三个播放通道重复请求约 290KB 的诺丁城 BGM

## 1.3.1 - 2026-08-16

- 新增 96 段普通话录制旁白，覆盖世界序章、六种武魂开局、时间线重启与全部 88 个正式剧情选择；小米微信和安卓 WebView 不再依赖系统 `speechSynthesis`
- 固定剧情优先使用网页 MP3 自动播放，动态 AI / 自由输入内容在设备支持时继续回退中文系统语音；播放期间继续自动压低 BGM
- “重新创建角色”增加二次确认弹层，明确提示角色、时间线、结局、关系、行囊和战斗记录会从当前设备删除
- 为 15 种行囊物品接入一一对应的游戏原画图标，并将整套运行资源压缩到约 416KB、按需加载
- 新增无系统语音环境、兼容旁白、物品原画与清档确认的手机自动化测试
- 移除会拖慢国内手机首屏的 Google Fonts 远程依赖，改用系统中文字体；预加载首屏手机版背景与魂力徽记，并将人声旁白压缩为 32kbps

## 1.3.0 - 2026-08-16

- 新增公网 AI 运营控制层，服务商、主备顺序、默认模型、限流策略和调用记录持久化到 Sites D1
- 每个服务商支持多个模型，可自动同步 `/v1/models` 或手动添加，并可选择默认模型

- 本机可视化中台改为公网控制入口；关闭本机不会影响公网游戏，公网继续使用最后保存的配置
