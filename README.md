# 斗罗大陆人生模拟器（手机版可玩版）

这是根据原始 Markdown 设定和用户选定的第三套视觉方案制作的手机端剧情人生模拟游戏。

当前 1.5.0 版本包含 184 个连续“原著同行”主线场景：从六岁武魂觉醒开始，完整经历诺丁六年、第一次猎魂、史莱克入学、大斗魂场、魂师精英赛、五年之约、海神岛与大陆终局。原有重大事件之间新增余波与幕间准备，补足学院日常、伤势恢复、物资、关系交流、训练复盘和事件后的情绪变化。沉浸模式体验全部 184 段，标准模式保留重大事件与余波，快速模式只走约 62 段核心线。玩家可选择六种武魂、出身、家庭、人生目标、个人秘密和叙事节奏；唐三、小舞与史莱克伙伴依照原著年代成长，玩家拥有独立关系与人生结局。自由行动和世界支线会优先使用已经验证的 AI；服务不可用时自动使用同一套本地剧情，不会中断主线。

真实手机会直接全屏运行游戏，不再套第二层手机外框；电脑预览保留 iPhone / Pixel 设备外观便于调试。

## 公网游玩

- 手机短地址：`https://fd918.github.io/douluo/`
- GitHub 短地址不内置任何真实密钥；玩家可在“档案 → 玩家自带 AI”填写自己的地址、模型和密钥，测试成功后启用，失败时继续使用本地剧情。

为控制长期游玩的 Token 消耗，系统每 12 个游戏轮次生成一次滚动剧情摘要；每名角色只保留并发送最近 10 轮完整对话。普通自由行动、人物对话和摘要请求默认关闭深度思考，并按内容类型限制单次输出长度。主 AI 不可用时会自动尝试备用服务，两者都失败时继续使用本地剧情。

游戏包含 8 条原创斗罗场景循环 BGM、6 条关键事件短音效和 1 条剧情选择确认音，会根据诺丁城、史莱克、星斗森林、战斗与人物关系自动切换。完整旁白包共 283 段：96 段兼容旧支线，187 段覆盖原著同行主线、幕间与结局；云希负责日常、训练和关系场景，云健负责觉醒、魂环、重大转折与终局。固定 MP3 加载失败时才回退设备中文系统语音。背景音与语音旁白互相独立，人声出现时 BGM 会柔和压低，可在剧情页暂停、重播或关闭，也可在“档案”页设置。

## 本地启动

在 macOS 终端进入本目录：

```bash
cd "/Users/tanwenjie/Documents/ChatGPT/斗破"
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

正常启动后，电脑访问 `http://localhost:4173/`。手机和电脑连接同一 Wi-Fi 时，可使用终端显示的局域网地址访问。修改代码后页面会自动刷新。

## AI 配置

GitHub Pages 默认预填 Agnes 的 API 地址和 `agnes-2.5-flash` 模型，密钥为空且只保存到玩家当前浏览器。Sites 服务端配置、公网可视化中台、更换服务商和安全要求见 `docs/AI_CONFIGURATION.md`。

世界观规则见 `docs/DOULUO_WORLD_BIBLE.md`，音乐接入与触发规则见 `docs/AUDIO_INTEGRATION.md`。
