# 斗罗大陆人生模拟器（手机版可玩版）

这是根据原始 Markdown 设定和用户选定的第三套视觉方案制作的手机端剧情人生模拟游戏。

当前版本包含角色创建、十章长期剧情、八个可收集结局、第二魂环三路分支、精英赛、瀚海航路、海神岛试炼、十一项成就、自定义行动、人物对话、属性战斗、行囊经济和完整时间线回溯。自由行动和人物自由对话会优先使用服务端 AI；AI 不可用时自动使用本地剧情，仍能从诺丁城完整玩到海神岛最终结局。

真实手机会直接全屏运行游戏，不再套第二层手机外框；电脑预览保留 iPhone / Pixel 设备外观便于调试。

## 公网游玩

- 手机短地址：`https://fd918.github.io/douluo/`
- AI 由独立安全服务端代理，上述静态页面不包含任何真实密钥。

为控制长期游玩的 Token 消耗，系统每 12 个游戏轮次生成一次滚动剧情摘要；每名角色只保留并发送最近 10 轮完整对话。普通自由行动、人物对话和摘要请求默认关闭深度思考，并按内容类型限制单次输出长度。主 AI 不可用时会自动尝试备用服务，两者都失败时继续使用本地剧情。

游戏包含 8 条原创斗罗场景循环 BGM 和 6 条关键事件短音效，会根据诺丁城、史莱克、星斗森林、战斗与人物关系自动切换。音乐可在“档案”页关闭，设置保存在当前设备。

## 本地启动

在 macOS 终端进入本目录：

```bash
cd "/Users/tanwenjie/Documents/ChatGPT/斗破/game"
npm run dev -- --host 0.0.0.0 --port 4173 --strictPort
```

正常启动后，电脑访问 `http://localhost:4173/`。手机和电脑连接同一 Wi-Fi 时，可使用终端显示的局域网地址访问。修改代码后页面会自动刷新。
